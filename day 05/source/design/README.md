## Исходники

`source/*.dc.html` — исходники артбордов холста. Это не код приложения и не шаблон для копирования. Это справочник: точные цвета, отступы, размеры шрифтов и тексты интерфейса. Сами по себе в браузере они не откроются, им нужен рантайм холста.

## Обложки на макетах

Цветные плашки с названием означают картинку обложки, извлечённую из EPUB. Светло-серые карточки с синей чертой («Мёртвые души», «Moby-Dick», «Сорок пять», «Отрочество») — запасной вариант, когда обложки в файле нет. Его рисует фронтенд.
