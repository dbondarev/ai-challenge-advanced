Примеры

in05 · тюн = gold. Match report за 25 april 2009. Gold: date = "25 april 2009". Разница не «научилась писать SELECT», а кавычки датасета. То же на in04, in07, in09, in10.

База — miss

SELECT match_report FROM table_name_4
WHERE date = '25 april 2009'

QLoRA — hit

SELECT match_report FROM table_name_4
WHERE date = "25 april 2009"

in03 · тюн хуже. Gold: SELECT length_feet FROM … AND name = "unnamed". База по смыслу верная (колонка), тюн меняет семантику на COUNT.

База — смысл верный

SELECT length_feet FROM table_name_28
WHERE mi_from_kingston > 84.5
  AND length_meters > 55.5
  AND name = 'Unnamed'

QLoRA — другая семантика

SELECT COUNT(length_feet) FROM table_name_28
WHERE mi_from_kingston > 84.5
  AND length_meters > 55.5
  AND name = "unnamed"

OOD. System prompt SQL на эти пять запросов не вешали.
