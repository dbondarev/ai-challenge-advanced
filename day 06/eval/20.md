### ood02 (out-of-domain)

В Bookreader API, запрос GET `/books?q=` используется для поиска книг на основе различных параметров. Этот метод позволяет вам фильтровать результаты поиска книги с помощью различных параметров.

### Функциональность GET `/books?q=`:
1. **Фильтры**:
   - `q`: Поиск по названию книги.
   - `author`: Поиск по автору книги.
   - `year`: Поиск по году издания книги.
   - `genre`: Поиск по жанру книги.
   - `publisher`: Поиск по издательству книги.
   - `language`: Поиск по языку книги.
   - `rating`: Поиск по оценке книги (например, "5", "4", "3" и т.д.).

2. **Примеры использования**:
   ```bash
   GET /books?q=title%20contains%20"Harry%20Potter"
   ```
   Этот запрос будет найти все книги, которые содержат слово "Harry Potter".

   ```bash
   GET /books?q=author%20contains%20"J.K."
   ```
   Этот запрос будет найти все книги,
```

**Tuned**

```
GET /books?q= используется для поиска книг на основе параметра q. В этом случае параметр q содержит запрос критерия поиска (например, "author" и "genre"). Это позволяет пользователям фильтровать книги по различным критериям.

В Bookreader API это может быть реализовано как фильтр в API, так и только в React. Если API предоставляет возможность фильтрации, то это будет доступно через API. Если же фильтры реализуются только в React, то они будут видны пользователю при использовании React.

Соответственно, можно использовать LIKE для фильтрации по колонке authors в JSON-объекте, если API поддерживает LIKE.

To reverse a singly linked list in Python, you can use the following approach:

1. Traverse the list and store each node's value.
2. Reconstruct the list in reverse order using the stored values.

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverse_list(head: ListNode) -> ListNode:
    # Store all nodes' values
    values = []
    current_node = head
    while current_node:
        values.append(current_node.val)
        current_node = current_node.next
