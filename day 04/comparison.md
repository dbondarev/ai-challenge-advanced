## Таблица: облако vs локальная

| Критерий | Облако (Cursor) | Локально (Ollama + Continue) |
|---|---|---|
| Качество кода | Многофайловая фича и профили дня 2 с первого раза после правил | Фича не собирается. Однометодный баг 7B чинит. 14B на 8 GB для кода вредна |
| Скорость | Дольше wall-clock (инструменты, репозиторий), ответ сильнее | 7B чат 7–32 с; 14B 1–2 мин; FIM ~1 с |
| Контекст проекта | Правила + дерево + tools | Явные файлы, 8k токенов. Без tools модель не запускает `check.sh` сама |
| Без интернета | Нет (Cursor cloud) | Без OpenAI/Anthropic — да. Без NetBird до nv307001 модели на Mac нет |

## Для чего хватает локальной

Хватает: inline-autocomplete (1.5B FIM), вопрос по одному файлу, точечный баг в одном методе, черновик патча без гарантии `check.sh`.

Незаменимо облако: фича на API + UI + тест за один промпт, агент с tools/MCP, ревью по всем правилам, первый зелёный `scripts/check.sh` без ручной склейки.

## Лучшая связка на RTX 3070 8 GB

**Чат:** `qwen2.5-coder:7b`, temperature **0.2**, top_p **0.9**, `num_ctx` **8192**.  
**Автокомплит:** `qwen2.5-coder:1.5b`, temperature **0.1**, `maxPromptTokens` 1024.  
**Embed:** `nomic-embed-text` на том же Ollama.

`qwen2.5:14b` на этой карте не брать для кода: веса ~8.4 GB, контекст 4096, задача теряется. `deepseek-coder:6.7b` медленнее 7B Qwen и хуже держит формат файлов.
